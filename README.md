# Социальный хаб

Три маршрута в одном статичном сайте:

- `/alexander` — личная страница Александра Чупина;
- `/choopa-play` — Choopa Play;
- `/art-of-movement` — «Искусство Движения».

Instagram намеренно не добавлен в публичные кнопки. Адреса Choopa Play оставлены как место для официальных ссылок, когда они будут готовы.

Для локального просмотра из этой папки:

```powershell
python -m http.server 4173
```

Затем открыть `http://localhost:4173/alexander`.
